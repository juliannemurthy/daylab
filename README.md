# Day Lab — Computational Analyses
Analysis scripts from my work as a graduate research associate in the Day Lab, Northeastern University.
Data, environments, and outputs are kept on the Explorer HPC and are not included.

| Directory | Analysis |
|---|---|
| `RNA-Seq/scripts` | Snakemake RNA-seq pipeline and differential expression analysis |
| `BETA/scripts` | CUT&Tag + RNA-seq integration with BETA |
| `ChIPseeker/scripts` | ChIPseeker peak annotations and differential expression analysis |
| `G4_Peak_Diff_Analysis/scripts` | Differential G4 peak analysis |

Related preprint: [G4 DNA structures induced by UV radiation: A multi-omic approach (bioRxiv, 2026)](https://doi.org/10.64898/2026.07.15.738736)
